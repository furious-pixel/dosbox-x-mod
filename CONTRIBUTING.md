# Contributing

This is an **experimental fork** of
[DOSBox-X](https://github.com/joncampbell123/dosbox-x), not the official
project.

- Vanilla emulator bugs, features, and patches belong upstream:
  https://github.com/joncampbell123/dosbox-x
- This repository is for Python mod support, OpenGL presentation, native CRT
  presets, and the Windows x64 SDL2 build. See [README.md](README.md).
- Pull requests may be restricted to collaborators. There is no monthly
  upstream-style release process here.

Build notes for this tree: [BUILD.md](BUILD.md).
