# Security Policy

This is an **experimental fork** of DOSBox-X. It is not the official project
and does not offer a supported-version list or security SLA.

- Vulnerabilities in **vanilla DOSBox-X** belong on
  [joncampbell123/dosbox-x](https://github.com/joncampbell123/dosbox-x).
  Do not use the upstream Discord for this fork.
- Issues that only exist in this fork's Python mod host, OpenGL presentation,
  native CRT path, or Windows x64 SDL2 build can be filed on this repository.
  Treat this tree as experimental.
